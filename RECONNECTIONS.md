# External-System Reconnections — Clean-Room Proof

## Gmail

System / provider: Gmail
Live owner: mailbox account owner
Connection / identity reference: ChatGPT Gmail connector
Required authority / scope: read-only mailbox search for proof
Verification: execute one bounded read-only mailbox search and record only success/failure, not message content

No password, token, message content or private mailbox data is stored here.

The Gmail system remains authoritative for mailbox state. This handoff exists only to prove that a fresh estate can name the external owner, connection reference, required scope and verification method without copying the live data into ARC.
